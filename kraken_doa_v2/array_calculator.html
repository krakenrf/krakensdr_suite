How the numbers are calculated

Wavelength λ = c / f. The spacing multiplier is the distance between neighbouring elements in wavelengths. Above 0.5 the array becomes ambiguous (grating lobes / phase wrapping), so 0.5 gives the largest — best resolving — array for a frequency, and an array of fixed size works from low frequencies up to the frequency where its spacing reaches 0.5λ.

Circular: spacing = 2·r·sin(π/N). Linear: spacing = length / (N−1). Patch / 3D: the layout is scaled so its largest nearest-neighbour distance equals the spacing multiplier × λ (for a flat ring or line this is the same rule).

Patch arrays are flat boards of patch antennas standing upright and facing the horizon (forward). They give azimuth and elevation (from the panel's width and height), but every element is in one vertical plane, so a bearing and its front/back mirror look the same — set the receiver's Direction to Forward only (applying the array from here does that). A patch is roughly λ / (2√εr) across (≈ 0.48 λ on air, ≈ 0.24 λ on FR4, less on ceramic), so the spacing must leave room for the patches themselves.

Est. resolution is the rule of thumb from the KrakenSDR array calculator spreadsheet: degrees(1.22 / D) / 10, with D the horizontal aperture in wavelengths (ring diameter / array length). For 3D arrays the elevation figure uses the vertical extent instead. It is an estimate of MUSIC's super-resolution, e.g. 10° means the source is somewhere within a 10° arc.

Coordinates use the receiver's convention: X = forward (the direction ANT0 points), Y = left, Z = up; circular elements are numbered clockwise seen from above, like the KrakenSDR arrays. A linear array's 0° is broadside (perpendicular to the line) and it cannot tell front from back.
